## Overview

AI Voice Note Pro is a Streamlit-based web application that allows users to record or upload audio, transcribes the audio using OpenAI's Whisper model locally, and generates intelligent structured summaries using either the OpenAI API or a local heuristic fallback. It also features text-to-speech capabilities for reading back the summaries.

## Data Flow

1. **Audio Acquisition:** User records via microphone (`audio_recorder.py`) writing a temporary `.wav` file, or uploads an audio file (`main_app.py` handles the file buffer).
2. **Transcription:** The application sends the audio path to `TranscriptionEngine`, returning the text and detected language.
3. **Summarization:** The transcribed text is submitted to `SummaryEngine` along with a prompt style. The engine returns structured data (Summary, Key Points, Action Items, Deadlines, Decisions).
4. **Playback/Export:** `tts_engine.py` generates `.mp3` for playback. Markdown strings are compiled representing the summary, enabling the user to save output to disk.
